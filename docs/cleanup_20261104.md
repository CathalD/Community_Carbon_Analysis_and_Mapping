# November 4 workshop cleanup

Implemented by request: central configuration, one saved mapping grid, focused
analysis blocks, console diagnostics and paired prediction/variance exports.

Preserved:

- Script 1's stock-to-depth function, stock summary expressions and all six
  observations in each reporting group. Field profiles are assumed complete at
  their recorded maximum; there is no new maximum-depth filter.
- Script 3's analysis, including predictors, formulas, raw-stock response,
  validation, AICc selection and native-resolution maps. Only configuration was
  changed; Script 4 handles the aligned comparison copy.
- The raw-core Bayesian model: exponential correlation, fixed range, configured
  log observation error and Gaussian conditioning using Cholesky solves.
- IDW power/neighbour search, now applied to log stock and nested by held-out plot
  for error calibration. The cloud/bin/selected variogram teaching plots remain.

Intentional scientific changes:

- Script 2 area-average and IDW models now operate on log carbon. Their prediction
  means include the lognormal variance correction; they differ from the previous
  raw-stock arithmetic averages and IDW predictions.
- Area/IDW likelihood errors are estimated on the log scale and shared with
  Script 5. Between-core SD and post-tuning RMSE are no longer mixed as if they
  were interchangeable error estimates.
- All final mapping and Bayesian rasters use the saved template and intersecting
  cell mask. Native covariates are preserved for the unchanged Script 3 analysis.
- Prepared prior stock, SD and log moments are computed once in Script 4.

Removed from the main execution path: nearest-core/Voronoi demonstration,
preliminary power-one IDW duplicate, repeated rasterization, repeated package
loads, unused summary labels, duplicate raw-core update loops, repeated local
error calibration in Script 5 and redundant map-fit comparison figures.

The optional old implementations are preserved under archive/development.
Rerun scripts 1-5 after installation; existing output files are not relabelled as
new results. The current products and uncertainty definitions are in README.md.

Validation in an isolated project copy:

- All five scripts completed. Script 1 stock values matched the previous output,
  retaining six finite observations in every depth group.
- Script 3's model evaluation table matched the previous output.
- All 43 final raster files tested shared the saved geometry; prediction means
  were positive and posterior variances and interval ordering were valid.
- Optional gstat and mvtnorm checks reproduced the Bayesian log moments to
