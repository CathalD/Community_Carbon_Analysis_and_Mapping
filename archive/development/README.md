# Original development scripts

These are unchanged copies of the handwritten duplicate and full package-comparison
experiment from before the November 4 cleanup. They document the earlier modelling
and input conventions and are not part of the current workshop execution path.

Use the numbered scripts for the workshop. The root `Testing_Bayesian_Models.R`
forwards to Script 5. The root `script_5_packages.R` is an optional numerical
comparison against the current Script 5 products and prints its results.
